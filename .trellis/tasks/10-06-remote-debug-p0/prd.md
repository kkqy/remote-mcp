# 远程调试三项 P0 能力

## 目标
让远程 Agent 直接取得结构化巡检、等待新日志和安全文件修改结果，减少反复空读、shell 拼接及盲目替换文件。

## 已确认背景与约束
- 基线 main 为 9a6336b；用户修改 `.opencode/package.json` 必须保留且排除提交。
- 已有 execution 输出使用字节游标、Base64、UTF-8 视图和截断标记；transfer 默认禁止覆盖、同目录临时文件校验后发布。
- Windows、Linux、macOS 的 amd64/arm64 均要求 CGO_ENABLED=0 可构建；构建与原生运行分别记账。
- 用户已授权创建任务并持续开展这三项能力；规划形成后直接推进。GUI 原生验收缺口保持在原任务，不能据此归档原任务。
- 会话、文档及源码注释中文；程序错误、提示、日志、CLI 帮助和 MCP/schema 描述英文；用户中文数据不改写。

## 范围与需求
### P0-1 巡检
结构化取得系统/架构、常用运行时可用性与版本、系统进程 PID/PPID 关系和监听端口占用 PID。有界网络探测分别表示 DNS、TCP、TLS、HTTP 阶段及失败阶段。不能把权限不足、缺少系统依赖、有限扫描或不支持平台伪装成完整成功；失败提供稳定代码和英文具体原因。

### P0-2 等待式读取
process_read、terminal_read 增加 0 到 30000 ms 有界等待，缺省保持立即返回。新输出、资源退出、等待超时、取消分别可识别；保留原游标、字节上限、Base64、UTF-8 与截断信息。日志文件跟踪支持显式打开/读取/关闭，处理轮转与截断，提供代际标识；有句柄上限、空闲回收及关闭取消。

### P0-3 文件操作
提供有界单目录浏览、按行读取 UTF-8 文本、目录文本搜索和行补丁修改。搜索有深度、条目、总扫描字节、每文件字节及结果上限。读取返回内容哈希以供修改。补丁必须匹配原文件 SHA-256；检测到冲突或失败时保留原目标、清理临时文件；保留未修改字节、中文内容及 LF/CRLF，限制文件及补丁规模。只修改已有普通文件，拒绝符号链接目标。

## 验收标准
- AC1：系统和常用运行时缺失均结构化表示；进程父子关系、监听 PID 可观察，权限/依赖失败不隐瞒；所有扫描有界。
- AC2：本地 DNS/TCP/TLS/HTTP 成功和失败测试分别识别阶段；超时/取消结束调用，HTTP 不无限读取或跟随重定向。
- AC3：旧参数立即读取；延迟输出唤醒；退出/等待超时/取消明确；无丢失唤醒或数据竞争；真实 PTY 仍能读取。
- AC4：日志追加、路径轮转、同文件截断、缺失/非普通文件、并发关闭/取消、句柄限制和到期清理都有测试。
- AC5：目录/搜索预算耗尽显式 truncated；中文按行读取，长行/超限/无效 UTF-8 明确处理。
- AC6：正确哈希补丁成功；错误哈希、并发本模块修改、无效补丁、写入失败保留原文件；CRLF、末尾无换行、空文件及中文均覆盖。
- AC7：独立 JSON-RPC 工具发现及调用成功；错误带稳定 code/message；新增错误诊断不泄漏内容或凭据。
- AC8：gofmt、vet、全量测试、race、六组合无 CGO 构建、本机实际二进制冒烟通过；Windows/macOS 原生未执行如实标明。

## 范围外
DAP 断点调试、聚合调试会话、诊断包、反向隧道和新增 GUI；非合作外部写入者之间严格原子哈希比较交换、文件创建/删除/任意二进制编辑。
