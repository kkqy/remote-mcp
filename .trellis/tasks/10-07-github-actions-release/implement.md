# 实施与检查计划
1. 实现四组压缩包与校验文件脚本及必要离线测试；运行诊断英文，临时夹具 .tmp/。
2. 扩展 check.yml 的标签打包 artifact、依赖验证的发布 job，保留原生验证与旧 artifact。
3. 更新 README 下载入口、版本标签示例、权限、重复 Release/失败草稿处理。
4. 执行脚本语法及离线边界测试、四组合构建和实际压缩包字节/权限/哈希核验、工作流语法检查；生产行为未变，避免无依据扩大验证。
5. trellis-check 独立核对，根会话更新规范并按提交阶段规则收尾。

使用仓库 .tmp/ 设置 TMPDIR/TMP/TEMP、GOCACHE、GOTMPDIR。未指定真实版本号前不创建标签/Release；如需在线验证，明确区分运行状态与配置存在。
