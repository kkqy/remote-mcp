# GUI 图形操作与截图能力

## 目标与用户价值

让 Agent 通过 MCP 观察远程图形桌面、执行鼠标键盘操作，再通过截图确认界面结果，完成图形应用调试闭环。

## 背景与仓库证据

- 项目为 Go MCP 服务，当前目标系统下限见 `.trellis/tasks/10-04-go-remote-debug-mcp/prd.md:41`。GUI 功能还要求可访问的用户图形会话及平台相关依赖，不能把原终端系统下限当作 GUI 兼容承诺。
- 现有文件、进程、终端和 TCP 转发模块从 `internal/server/server.go:65` 开始集中注册，尚未有 GUI 模块。
- 原远程调试任务在 `.trellis/tasks/10-04-go-remote-debug-mcp/prd.md:69` 排除了图形桌面；本任务独立补充该能力，不改写旧任务验收范围。
- 现有构建无需 CGO，见 `README.zh-CN.md:9` 和 `scripts/build.sh:12`，覆盖三个系统的 amd64/arm64。
- 开发环境为 Linux/amd64，见 `README.zh-CN.md:200`。跨平台构建、真实桌面运行和实际 MCP 客户端图片展示须分别记录。
- 已查询项目历史中的“截图”，未发现本会话之外的既定方案。

## 已确认的关键决策

- 用户授权创建任务并进入规划；首版采用截图加坐标式鼠标键盘操作。
- Wayland 必须纳入首版；以 GNOME 和 KDE 为完整截图与操作验收目标。其他桌面根据实际能力报告，不承诺 Sway/Hyprland 完整输入控制。
- 中文文本优先直接输入；缺少直接文本能力时允许剪贴板粘贴兼容。保存并恢复原内容；无法可靠保存或恢复时默认拒绝，只有调用方明确允许替换才继续。
- 文档、会话与注释使用中文；不在用户页面展示开发需求文字。
- 用户追加要求：程序自身的错误、提示、日志、CLI 帮助及 MCP 工具/schema 描述使用英文；不翻译实际用户输入、剪贴板、文件或终端数据。

## 首版范围与需求

以下将作为最终审阅的完整实施范围；其中截图粒度、会话及授权边界在本次摘要中统一审阅。

| 编号 | 可观察行为 |
| --- | --- |
| GUI-01 | 查询图形后端、会话状态、显示器和可用截图/鼠标/键盘/文本能力；明确缺失依赖或权限原因。只读查询不发起授权弹窗。 |
| GUI-02 | 对 Windows、macOS、Linux X11 及 Wayland GNOME/KDE 的当前用户图形桌面提供完整操作闭环；能力按实际系统权限与依赖探测。 |
| GUI-03 | 获取所选显示器的 PNG 截图，支持整显示器及显示器内区域裁剪，通过标准 MCP 图片内容返回。支持多显示器选择，但不提供全桌面拼图或窗口专用捕获。 |
| GUI-04 | 鼠标移动、点击、双击、拖拽、横向/纵向滚动；使用截图内像素坐标与显示器标识，正确映射到系统逻辑坐标。支持负桌面坐标、混合缩放和屏幕布局变化；旧布局坐标须拒绝。 |
| GUI-05 | 支持单键、组合键和 UTF-8 文本（包括中文）。一次按键/拖拽调用结束后释放由本工具按下的键及按钮，失败不能隐瞒可能已经发生的输入。 |
| GUI-06 | 剪贴板兼容输入明确报告模式和恢复状态，不记录或泄漏原剪贴板内容；发现其他应用已修改剪贴板时不覆盖其新内容。无法可靠保存/恢复时，默认失败；显式允许替换为独立调用选项。 |
| GUI-07 | 显式打开/关闭图形会话；Wayland 使用系统 Portal 授权，用户可取消或撤销。只操作实际获授权的屏幕和设备；MCP 连接断开可继续使用存活的图形资源，服务重启后资源失效。 |
| GUI-08 | 输入串行执行，操作后可再次截图确认画面。结果标明采集时间/新鲜度；无新帧或采集失败明确说明，不把输入接收成功等同于应用已渲染。 |
| GUI-09 | 无 GUI、无权限、依赖缺失、授权取消/撤销或后端不支持时返回稳定业务错误；这些情况不妨碍已有服务启动和工具使用。会话、缓冲、等待和输入大小均有上限。 |
| LOG-01 | 用户于 2026-10-06 追加：MCP 调用失败的运行日志须输出可诊断的错误码和具体原因，不能只有 `failed=true`。覆盖 GUI、文件、执行、转发及 SDK 参数/协议错误；保留原工具名、耗时和失败标志，不记录敏感调用参数或内容。 |
| LOG-02 | 用户于 2026-10-06 追加：程序自身的错误和提示改为英文，覆盖 MCP message、能力原因、日志、CLI/HTTP/配置及验证程序用户提示。保持错误码、字段、接口和流程，不影响中文 UTF-8 用户数据；文档与注释仍中文。 |

## 范围外

- 按控件名称定位、可访问性树读取、语义 GUI 操作和 OCR。
- 实时视频服务、远程桌面网页、桌面拼图和按窗口选择的专用截图工具。
- Sway/Hyprland 专用输入后端，以及保证所有 Wayland 合成器完整可控。
- 系统提权、绕过桌面授权、锁屏登录、安全桌面、跨用户图形会话选择或自动配置系统服务。
- 跨服务重启保存 GUI 资源或 Portal 恢复令牌；运行期间允许复用已授权会话。

## 技术说明与实施风险

- 平台事实与候选方案分别见 `research/platform-boundaries.md`、`research/wayland.md`；研究尚未完成真实 GUI 运行验证。
- Wayland 使用当前用户会话 D-Bus、RemoteDesktop/ScreenCast Portal 和 PipeWire；依赖桌面组件及授权，首次或恢复授权失效时可能需要目标机器用户确认。
- 维持无 CGO 六组合构建。首选研究已查证的 Go D-Bus 加 GStreamer PipeWire 采集路线；动态系统库路线为备选。运行时 GUI 依赖须明确列出，缺失时不阻断旧功能。
- 媒体帧格式、中文粘贴、剪贴板恢复及平台坐标变换将在实施第一阶段验证。若原型暴露需改变已审阅的范围、安装条件或构建契约，先修改规划并重新审阅，不能删去 Wayland 交付。
- GNOME/KDE 的最低可用版本以实际接口、依赖和原生验证为依据，不将上游源码存在当作所有发行版均兼容。
